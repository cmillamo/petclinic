# Working in this repository

- Build and test with `./mvnw`. `./mvnw test` runs the whole suite. The build checks formatting; `./mvnw spring-javaformat:apply` fixes it.
- Evidence: label each claim you make about this code VERIFIED (you ran it or read the line, and say which), INFERRED (say from what) or UNKNOWN.
- Before writing code for a ticket, list what it leaves undecided. Ask about anything a user of the application would notice. For choices inside the code, choose, and say what you chose and why.
- Name each test as a sentence that states the behaviour it checks. The test class names the subject. Use the present tense, and no `test` prefix.
